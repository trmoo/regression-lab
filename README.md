# 📈 회귀 분석의 핵심개념 탐구

고등학교 「데이터 과학」 **회귀 분석 모델** 학습지를 브라우저에서 직접 조작하며 공부하는 앱입니다.

## 쓰는 법 (학생)

1. `dist/index.html` 을 더블클릭하거나 선생님이 알려 준 주소를 엽니다. 인터넷이 없어도 됩니다.
2. 위쪽 차례(0 ~ 7)를 따라 빈칸을 채우고 **[✔ 확인]** 을 누릅니다. 틀린 칸은 빨갛게 표시되고 💡 힌트가 나옵니다. 정답은 보여 주지 않으니 힌트를 보고 스스로 고쳐 보세요.
3. 처음 화면에서 **학번·이름**을 적고, 틈틈이 **위쪽 띠의 [💾 저장하기]** 를 누릅니다.
   지금까지 한 활동이 담긴 **이 앱 파일 그대로**가 바탕 화면에 `회귀분석_학번_이름.html` 로 저장됩니다
   (처음 한 번만 저장 창이 바탕 화면으로 열리고, 그다음부터는 창 없이 그 파일에 덮어씁니다).
4. 다음 시간에는 **바탕 화면의 그 파일을 더블클릭**하면 「본인의 활동이 맞나요?」 를 물은 뒤 하던 곳부터 이어서 합니다.
   다 마치면 그 파일을 제출합니다. 데이터과학 수행평가 시험지(A~D형)와 같은 방식입니다.

## 화면

| 차례 | 학습지 | 해 보는 것 |
|---|---|---|
| 0 문제 상황 | [표1] | 광고비·매출액 산점도, x = 10 일 때 눈대중 예측 (답은 3절을 마치면 열림) |
| 1 독립·종속 변수 | 1절 | 빈칸, 변수 짝에서 독립 변수 고르기 → 「원인 ➜ 결과」 화살표 |
| 2 상관·인과 | 2절 | 빈칸, 문장 ①~⑤ 판정과 해설, 숨은 원인 쓰기 |
| 3 선형 회귀 | 3절 | **손잡이를 끌어 직선을 직접 긋기** → 예측값·오차·오차² 표가 바로 바뀜, 오차 막대·오차² 정사각형, 짝꿍과 비교, 「오차의 합 vs 제곱합」, 최소제곱 직선(65.9)과 견주기 |
| 4 상관관계 분석 | 4절 | 빈칸, 기울기·흩어짐 미끄럼 막대로 r 실험(도전 과제 2개), r 네 개의 방향·강도 |
| 5 오차와 평가 지표 | 5절 | y = x 표 채우기(MAE·MSE), 오차 −3 인 점을 움직여 MSE 가 더 커지는 까닭 보기 |
| 6 결정 계수 | 6절 | 세 걸음 — ① 평균으로 짐작(주황) ② 직선으로 짐작(초록 + 파랑으로 쪼개짐, 점을 눌러 숫자로) ③ 226 = 160.1 + 65.9 → R² 0.71 |
| 7 두 가지 회귀 | 7절 | 점을 눌러 학습/평가 데이터를 나누고 평가 MSE 보기(학습지 그림대로면 3.94), 표 채우기 |
| 📄 내 활동지 | — | 내 직선 그래프·표·답·서술을 활동지 한 장으로 모아 보기(선생님이 제출 파일을 열어 여기서 확인) |

## 선생님께

- 앱 안에는 정답을 보여 주는 단추가 없습니다(학생은 💡 힌트만 봅니다). 정답은 학습지 정답지를 쓰세요.
- 서버가 없습니다. 활동은 그 탭(sessionStorage — 탭을 닫으면 지워짐)과 학생이 저장한 파일에만 남고, 학번·이름은 PC 에 남지 않습니다.
- 제출받은 `회귀분석_학번_이름.html` 을 열면 「본인 확인」 창에서 [네] 를 누른 뒤 「📄 내 활동지」에서 그 학생의 활동을 볼 수 있습니다.
- 저장하지 않고 창을 닫으려 하면 브라우저가 한 번 묻습니다.

## 개발

```bash
npm install
npm start            # 개발 서버
npm test             # 학습지 숫자·정답 대조 (225가지)
npm run check:syntax # 소스 전수 문법·저작권·규칙 검사
npm run build        # dist/index.html 한 파일 + 빌드 점검
```
